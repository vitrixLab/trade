# Global and Local Major Events Ledger

Use this ledger to record events that may affect markets, instruments, sectors, currencies, rates, liquidity or portfolio risk. One event per record. Do not enter an event as verified until its source is captured.

## Event record template

| Field | Required content |
|---|---|
| Event ID | Stable ID, e.g. EVT-YYYYMMDD-001 |
| Event title | Neutral factual title |
| Geography | Global / regional / country / other |
| Category | Central bank / inflation / GDP / employment / fiscal / election / geopolitics / conflict / trade / commodity / regulation / earnings / corporate action / disaster / other |
| Event time | Original published time and timezone |
| Effective time | When the event/policy takes effect, if different |
| Recorded at | UTC and local |
| Source | Primary source URL and publisher |
| Evidence status | FACT / ESTIMATE / HYPOTHESIS / UNKNOWN |
| Surprise vs consensus | Actual, consensus, prior and source; otherwise N/A |
| Transmission channels | Rates, FX, risk appetite, earnings, supply chain, liquidity, sector, etc. |
| Potentially affected assets | Verified symbols / asset classes |
| Initial market reaction | Price, volume, yield, FX move and observation window |
| Expected vs actual | What was expected and what happened |
| Scenario impact | Bull / base / bear implications |
| Confidence | Low / medium / high with rationale |
| Follow-up | Next release, hearing, policy date or confirmation |
| Analyst notes | Competing interpretations and uncertainties |

## Event-analysis method

1. Capture the original announcement and timestamp.
2. Separate the event fact from market interpretation.
3. Record consensus and prior values only when sourced.
4. Map plausible transmission channels to the region and relevant holdings.
5. Measure the reaction over pre-defined windows (e.g. event day, +1, +5, +20 trading sessions) using timestamped data.
6. Compare reaction with a benchmark and relevant peers.
7. Note confounders and concurrent events; do not claim causality without a defensible design.
8. Reassess the thesis and log whether the event changed the decision.

## Coverage checklist

- Central bank policy meetings and communications
- Statistics agency CPI, GDP, labor, trade and other releases
- Exchange issuer disclosures, earnings, dividends, rights offers, suspensions and other corporate actions
- Government budget, tax, debt auctions and regulatory changes
- Federal Reserve, ECB and other major central-bank decisions
- Global macro releases and trade-policy changes
- Geopolitical events, sanctions, shipping disruptions and energy shocks
- Major global equity, bond, FX and commodity regime changes

## Empty ledger

No events are pre-populated as current or verified. Add records only with source evidence.
